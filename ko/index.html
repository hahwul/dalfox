Dalfox는 XSS를 사냥합니다.

Rust로 작성한 반사형, 저장형, DOM 기반 XSS 오픈소스 스캐너입니다. 파라미터를 찾아내고, 컨텍스트마다 탐침을 보내고, 파싱한 HTML과 JavaScript에서 실행을 확인한 뒤에야 결과로 보고합니다.

명령줄, REST 서버, MCP 도구 어느 쪽으로 실행해도 같은 엔진이 돌고, 모든 결과에는 근거 등급이 붙습니다.

install

바이너리 하나. 따로 준비할 것은 없습니다.

  • Homebrew
  • Snap
  • Arch (AUR)
  • Chocolatey
  • Nix
  • Cargo
  • Docker
$ brew install dalfox

macOS, Linux, Windows용 빌드 바이너리는 릴리스 페이지에 있습니다. Docker와 소스 빌드를 포함한 모든 설치 경로는 설치 가이드에서 다룹니다.

run

명령 하나로, 검증된 결과까지.

대상만 지정하세요. 파라미터를 찾고, 컨텍스트마다 살아남는 문자를 탐침하고, 페이로드를 주입한 뒤 파싱한 DOM에서 실행을 확인하고 나서야 보고합니다.

[V]는 페이로드가 단순히 되돌아온 것이 아니라 파싱된 응답 안에서 실행 위치에 놓였다는 뜻입니다. 등급별 의미는 탐지 모델에서 설명합니다.

what it does

XSS 워크플로 전체를 스캐너 하나로.

discover
쿼리, 본문, 경로, 헤더, 쿠키, 폼, 프래그먼트에서 파라미터를 찾고, DOM과 워드리스트, JSON 키에서 더 캐냅니다.
probe
문자 단위 탐침으로 파라미터가 어디에 놓이는지, 어떤 문자가 살아남는지 알아내고, 그 자리에서 통할 수 있는 페이로드만 보냅니다.
verify
HTML 파서와 JavaScript AST로 실행되는 반사와 단순히 되돌아오는 반사를 구분합니다. 모든 결과에 근거가 붙습니다.
evade
주요 WAF를 식별하고 인코딩, 대소문자, 공백, 엔티티 변형으로 페이로드를 바꿔 우회를 시도합니다.
pipeline
URL, 파일, stdin, 원시 HTTP 요청, HAR, OpenAPI를 읽습니다. CI에서 크롤러, 프록시, 정찰 도구 뒤에 바로 이어 붙일 수 있습니다.
report
Plain, JSON, JSONL, Markdown, TOML, 그리고 GitHub 코드 스캐닝용 SARIF. 요청과 응답 본문은 요청했을 때만 포함합니다.

modes

여섯 가지 실행 방식.

대상에 맞는 형태를 고르세요. 어떤 모드든 같은 탐색·검증 엔진을 공유합니다.

$dalfox scan https://target.app

URL 하나를 스캔합니다. 파라미터를 캐내고, 컨텍스트마다 탐침하고, 모든 적중을 파싱한 응답에서 확인합니다.

$dalfox scan urls.txt

한 줄에 URL 하나씩 적힌 파일을 읽어 대상 목록을 리포트 하나로 스캔합니다.

$cat urls.txt | dalfox scan

stdin에서 대상을 읽어 크롤러나 정찰 파이프라인의 맨 끝에 놓을 수 있습니다.

$dalfox scan https://app/post --sxss --sxss-url https://app/feed

한 엔드포인트에 주입하고, 저장된 페이로드가 나타나는 페이지에서 확인합니다.

$dalfox server

비동기 스캔 작업, 연동, 대시보드를 위한 장기 실행 REST API로 띄웁니다.

$dalfox mcp

에이전트와 IDE가 대신 스캔을 돌릴 수 있도록 MCP 도구로 노출합니다.

community

공개된 곳에서, 세계의 헌터들과 함께.

Dalfox는 직접 쓰는 사람들이 만들어 갑니다. 이슈를 열고, 풀 리퀘스트를 보내고, 페이로드를 커뮤니티와 나눠 주세요.
